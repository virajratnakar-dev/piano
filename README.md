# 🎹 Viraj's Mini Piano

A simple and interactive browser-based piano built using HTML, CSS, and JavaScript (Web Audio API).
Play notes, visualize keys, and even listen to a sample melody directly in your browser!

🌐 Live Demo

👉 https://viraj-piano.netlify.app

✨ Features

🎼 Play piano notes by clicking keys

🎵 Supports multiple octaves (C4 → B5)

🎧 Built using Web Audio API (no external libraries)

🎹 Realistic keyboard layout (white + black keys)

🎤 Built-in sample melody ("Demons" intro)

🔴 Visual key highlight while playing sample

🏷 Toggle note labels (show/hide notes)

📱 Fully responsive design

🛠 Tech Stack

HTML5

CSS3

JavaScript

Web Audio API

🚀 How to Use
1. Clone the repository
git clone https://github.com/your-username/mini-piano.git
2. Open the project

Just open the index.html file in your browser.

🎮 Controls
Button	Function
Sample	Plays a demo melody
Stop Sample	Stops the melody
Show/Hide Notes	Toggles note labels on keys
Click Keys	Plays individual notes
🎼 Notes Supported

The piano includes:

White keys: C4 → B5

Black keys: sharps like C#4, D#4, F#4...

🔊 How It Works

Uses OscillatorNode to generate sound waves

Frequencies are mapped manually for each note

Smooth audio envelope:

Quick attack

Gradual decay
